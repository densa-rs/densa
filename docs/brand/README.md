# densa brand

The mark is a D built from the rows of a data grid, leaning forward; the green cell is a value
that just changed. The wordmark is set in JetBrains Mono, the font densa ships, converted to
outlines. Tagline: **Dense by design** (kept out of the logo files, so it can change freely).

## Files

| File | Use |
|---|---|
| `densa-logo.svg` | Mark and wordmark, on light backgrounds |
| `densa-logo-dark.svg` | Mark and wordmark, on dark backgrounds |
| `densa-mark.svg` / `densa-mark-dark.svg` | Mark alone, light / dark backgrounds |
| `densa-mark-mono-ink.svg` / `densa-mark-mono-white.svg` | One-color mark, where color is unavailable |
| `densa-favicon.svg` | Browser tabs and other sizes up to 48 px (pixel-aligned at 16 px) |
| `apple-touch-icon.png` | 180 px home-screen icon |
| `densa-avatar-512.png` | GitHub organization avatar |
| `densa-mark-512.png` | Mark as a 512 px PNG |
| `densa-social-1280x640.png` | GitHub repository social preview |

## Colors

| Name | Hex | Use | Contrast |
|---|---|---|---|
| Ink | `#0B1220` | Dark backgrounds, text on light | 18.7:1 on white |
| Densa Blue | `#2F5BEA` | Mark on light; background for white text | 5.5:1 with white |
| Blue Light | `#6B9BFF` | Mark and text on dark | 6.9:1 on Ink |
| Signal | `#16A34A` | The changed cell, on light (graphics only) | 3.3:1 on white |
| Signal Light | `#2BD576` | The changed cell, on dark | 9.7:1 on Ink |
| Slate / Slate Light | `#5B6B82` / `#94A3B8` | Secondary text on light / dark | 5.4:1 / 7.3:1 |

## Rules

- Keep clear space around the mark of at least one row height (12% of its height).
- Do not recolor the rows individually, add effects, or straighten the slant (except the
  favicon, drawn upright for 16 px).
- Use the dark files on dark backgrounds rather than placing the light ones on a box.
- Below 48 px use the favicon.
